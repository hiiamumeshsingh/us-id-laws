Federal standard

REAL ID, explained simply.

Separate the federal standard from each state's implementation and application process.

Federal standard

REAL ID establishes minimum standards for certain state-issued driver's licenses and identification cards used for federal purposes.

  • Identity and date of birth
  • Social Security documentation
  • Residential address documentation
  • Lawful-status documentation where applicable
