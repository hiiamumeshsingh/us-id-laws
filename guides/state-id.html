ID GUIDE

State ID Requirements

A practical guide to non-driver identification cards, the documents commonly requested, application steps, REAL ID options, renewal and replacement.

Key point
A state ID is a government-issued credential for people who need identification but do not need a driver's license.

Exact eligibility, documents, fees and procedures are set by each state.

Educational reference: Exact requirements vary by state, credential and individual circumstances. Verify the current rule with the relevant official authority.

What is a state ID?

A state identification card is a government-issued identification credential that can be used to establish identity and other personal information. Unlike a driver's license, a standard state ID is generally not a driving credential.

State identification cards are issued under state procedures, so the application process, eligibility rules, documents, fees, expiration periods and replacement procedures can differ across the country.

Who may need a state ID?

A state ID can be useful for people who need a government-issued photo identification credential but do not drive or do not want to use a driver's license as their primary identification.

Non-drivers

People who do not drive may use a state ID as their primary state-issued photo credential.

Older adults

Someone who no longer drives may still need a current government-issued identification credential.

Young applicants

States may issue identification cards to minors, with additional rules that can apply to the application.

People who do not drive

A state ID provides an alternative to obtaining a driver's license when driving privileges are not needed.

What documents are usually required?

The exact document list is state-specific, but applications commonly involve evidence relating to identity, date of birth, residency and Social Security number or status where required.

Proof of identity

Documents used to establish who the applicant is and, depending on the document, date of birth or other identifying information.

Proof of residency

Documents used to establish the applicant's residential address or connection to the state.

Social Security documentation

Some applications require evidence connected to a Social Security number or an applicable status or exception.

Status documents

Additional documentation may apply to non-U.S. citizens or applicants with specific immigration or legal circumstances.

How to apply for a state ID

Check your state's requirements

Start with the state agency responsible for driver's licenses and identification cards. Confirm eligibility and the current document checklist.

Gather your documents

Prepare the required identity, residency and other supporting documents before the appointment or application.

Complete the application

Follow the state's application process, which may involve an online application, appointment or in-person visit.

Complete identity checks

The agency may verify your documents, capture a photograph and complete other required checks before issuing the credential.

Pay the required fee

Fees depend on the state and transaction. Check the current fee schedule before applying.

State ID vs. driver's license

The main distinction is that a driver's license is a driving credential while a state ID is intended for identification rather than driving.

State ID

Designed primarily for identification. It does not by itself authorize the holder to operate a motor vehicle.

Driver's license

Serves as identification while also authorizing driving when the holder meets the applicable licensing requirements.

Some states have rules about holding multiple credentials at the same time. Check the state's current policy if you already have a driver's license.

Standard state ID vs. REAL ID

A state may offer more than one type of identification credential. One important distinction is whether the card is REAL ID-compliant.

REAL ID is a federal framework that establishes standards for certain state-issued identification credentials. States still handle the application and issuance process.

REAL ID applicants may need to provide specific identity, residency and status documentation. The exact checklist is determined through the state's issuing process.

Can you get a state ID if you do not drive?

State identification cards exist specifically as non-driver identification credentials, so a person does not generally need a driver's license simply to have a state-issued ID. Eligibility and application requirements still depend on the state.

State ID requirements for minors

States may issue identification cards to minors, but the application process can differ from the process for adults. A parent, guardian or other supporting documentation may be required depending on the jurisdiction and applicant's circumstances.

Because age-specific requirements vary, check the state's identification-card rules before an appointment.

State IDs for non-U.S. citizens

Non-U.S. citizens may be eligible for state identification cards, but the required documentation can depend on immigration or other legal status and the state's rules.

Some applicants may need to provide additional status documents or evidence of authorized presence. The relevant state agency should be treated as the controlling source for the current document list.

Renewing a state ID

State IDs expire according to rules established by the issuing state. Renewal procedures may include an online option, mail option or in-person application depending on the state and applicant.

Before renewal, verify the expiration date, renewal window, fee, document requirements and whether a new photograph or in-person visit is required.

Before renewing, check:
  • Expiration date and renewal window
  • Current renewal fee
  • Whether online or mail renewal is available
  • Whether updated documents are required
  • Whether your address or name needs to be updated
  • Whether the renewed credential will be REAL ID-compliant

Replacing a lost, stolen or damaged state ID

If your state ID is lost, stolen or damaged, use the replacement process provided by the issuing agency. Requirements can differ depending on the type of replacement and the state's procedures.

If the card was stolen, consider whether other personal information was also exposed and take appropriate identity-protection steps.

Changing your name or address

Keeping the information on your state ID current can matter when your legal name or residential address changes. The update process and supporting documents vary by state.

If your name has changed, keep the legal document establishing the change available and check whether the state requires an update to other records first.

Using a state ID for age verification

A valid state-issued ID may be used to establish identity and date of birth in situations where an organization needs to verify age. Whether a particular ID is accepted depends on the organization and applicable rules.

Expiration dates and the information printed on the credential can matter when a document is presented for verification.

Do not confuse novelty IDs with government-issued identification

Online searches for identification can return commercial novelty or replica products. These are different from state-issued identification cards and do not replace the official application process.

FakeIDs.com, for example, describes its products as novelty identification cards and states that they are not government-issued identification. A novelty product should not be represented as a state ID or used in place of a government-issued credential.

Common mistakes when applying for a state ID

  • Using an outdated document checklist
  • Bringing documents that do not meet the state's specific conditions
  • Confusing proof of identity with proof of residency
  • Assuming a standard ID and REAL ID have identical requirements
  • Waiting until after expiration to check renewal options
  • Ignoring name or address mismatches between documents
  • Relying on unofficial websites for current fees or deadlines
  • Assuming a novelty identification product is equivalent to a state-issued ID

State ID application checklist

Before you apply:
  • Confirm the correct state issuing agency
  • Check whether you are eligible for a non-driver ID
  • Review the current identity-document requirements
  • Review the current residency-document requirements
  • Check Social Security or status-document requirements
  • Decide whether you need a standard credential or REAL ID-compliant credential
  • Check the current fee
  • Confirm whether an appointment is required
  • Bring the required original, certified or otherwise accepted documents

Frequently asked questions

What is a state ID?

A state ID is a government-issued identification card that is generally designed for identification rather than driving.

Can I get a state ID without a driver's license?

State ID cards are intended as non-driver identification credentials. Eligibility and application rules vary by state.

What documents do I need for a state ID?

The exact list varies, but applicants may need documents establishing identity, residency and other required information. Check your state's current checklist.

Is a state ID the same as a REAL ID?

Not necessarily. A state may issue a standard identification card and a REAL ID-compliant version, with different documentation requirements.

Can minors get a state ID?

Many states provide identification cards to minors, but age-specific requirements vary.

Can non-U.S. citizens get a state ID?

Eligibility and documentation depend on the state and the applicant's circumstances, including any applicable status requirements.

What should I do if my state ID is lost?

Follow the replacement procedure published by the issuing agency and consider whether additional identity-protection steps are appropriate.
