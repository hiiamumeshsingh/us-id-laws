Oregon ID Laws: What You Need to Know

Oregon offers standard and REAL ID driver licenses, permits and identification cards. This guide covers Oregon's document requirements, residency proof, REAL ID, voting rules, renewal, replacement, fees and requirements for non-U.S. citizens.

Last reviewed: September 26, 2026

Oregon driver's license requirements

To qualify for a standard Oregon driver's license, instruction permit or identification card, an applicant must be an Oregon resident. DMV requires proof of identity with the applicant's full legal name and date of birth, proof of current residence address and a verifiable Social Security number if one has been assigned. citeturn0search0

Standard driver's license

A standard credential is not REAL ID-compliant. The identity and date-of-birth document must be an original or certified copy from an accepted source. Oregon DMV provides a detailed list of acceptable documents, including qualifying birth certificates, passports, Consular Reports of Birth Abroad and federally recognized Oregon Tribal IDs. citeturn0search2

Driver testing

New drivers may need vision, knowledge and drive tests depending on the application and licensing history. Oregon also has provisional instruction-permit and licensing rules for younger drivers.

One valid credential

Oregon allows only one valid state ID or driver's license at a time. Issuance of an Oregon credential invalidates an out-of-state credential. citeturn0search0

Oregon state identification cards

Oregon identification cards have no minimum age limit. Applicants can obtain a standard ID or choose REAL ID when they meet the additional federal documentation requirements. citeturn0search0

Standard ID

A standard Oregon ID requires proof of identity and date of birth, current residence address and a verifiable SSN if one has been assigned. citeturn0search2

REAL ID ID card

A REAL ID identification card requires original or certified identity and lawful-status documents, Social Security documentation and two printed proofs of Oregon residence from different sources. citeturn0search1turn0search2

ID validity and fees

Oregon's current fee schedule lists an eight-year original standard ID at $47 and an eight-year original REAL ID at $77. citeturn0search0turn0search4

Documents needed for an Oregon ID

Oregon separates proof of identity/date of birth, Social Security information and residence address. The exact document set changes depending on whether the credential is Standard or REAL ID. citeturn0search2

Standard identity documents

Examples include an eligible U.S. birth certificate, U.S. passport or passport card, Consular Report of Birth Abroad and qualifying Oregon federally recognized Tribal ID. The document must generally be an original or certified copy and contain the required name and date-of-birth information. citeturn0search2

REAL ID identity and lawful status

REAL ID applicants can use documents such as a valid U.S. passport, U.S. birth certificate, Certificate of Naturalization, Certificate of Citizenship, Permanent Resident Card, Employment Authorization Card or qualifying foreign passport with the required U.S. immigration documentation. citeturn0search2

Social Security number

Standard applicants provide a verifiable SSN if one has been assigned. REAL ID applicants must provide a verifiable SSN or proof they are not eligible for one. Oregon DMV verifies the SSN against Social Security Administration records and requires the current legal name to match. citeturn0search0turn0search2

Proof of Oregon residency

Every Oregon license, permit or ID application requires proof of the applicant's current residence address. A mailing address such as a P.O. Box may be used in addition to the residence address but cannot replace it. citeturn0search0

REAL ID residency rule

REAL ID requires two printed proofs of residence address from two different sources. For REAL ID, a P.O. Box cannot be used in place of the physical residence address. citeturn0search1turn0search2

Oregon REAL ID requirements

Oregon REAL ID is optional. The state offers standard and REAL ID-compliant driver's licenses, permits and identification cards. citeturn0search1

REAL ID checklist

  • Original or certified proof of identity and date of birth
  • Proof of lawful U.S. status
  • Verifiable Social Security number or proof of SSN ineligibility
  • Two printed proofs of current Oregon residence address from different sources
  • Legal name-change documents when applicable
REAL ID requires an in-person original-document review. Oregon DMV does not issue an original REAL ID entirely online. Identity, date-of-birth and lawful-status documents must be originals or certified copies. citeturn0search1

Federal use

Starting May 7, 2025, adults generally need a REAL ID or another federally accepted form of identification for covered domestic air travel and certain federal facilities. Oregon's standard license is not accepted for those covered purposes by itself. citeturn0search0turn0search1

REAL ID fee

The REAL ID option adds $30 to the regular issuance, renewal or replacement fee each time the REAL ID option is selected. citeturn0search1

Delivery

After DMV accepts and scans the documents, Oregon says the permanent REAL ID card generally arrives by mail in about 20 days. The temporary paper credential is not accepted by TSA as a substitute for an acceptable travel ID. citeturn0search1

Oregon voter identification requirements

Oregon conducts elections primarily by mail rather than through traditional polling-place voting. Voter registration uses information from the Oregon DMV when available, including a driver's license, permit or ID number. If the voter does not have one, the last four digits of the Social Security number can be used. citeturn0search3turn0search5

If you do not have an Oregon DMV number or SSN

The Oregon Secretary of State says a voter registration application can be accompanied by another acceptable form of identification, such as valid photo identification, a paycheck stub, utility bill, bank statement, government document or qualifying UOCAVA/VAEH proof. citeturn0search5

Vote-by-mail process

Active registered voters receive an official ballot. Ballots can be returned by mail or deposited at an official drop box. Oregon's Secretary of State says ballots must be received or mailed with a valid postmark by 8 p.m. on Election Day. citeturn0search3

Registration deadline

Oregon's general registration deadline is 21 days before Election Day. For the 2026 general election, the deadline listed by the Secretary of State is October 13, 2026. citeturn0search5

Citizenship

Voters must be U.S. citizens. Oregon permits eligible 16- and 17-year-olds to register, but they do not receive a ballot or vote until an election occurs on or after their 18th birthday. citeturn0search3

Renewing an Oregon driver's license or ID

Oregon DMV offers online DMV2U services for eligible renewal and replacement transactions. Customers can also use DMV offices when an in-person transaction is required. citeturn0search1turn0search0

Driver license renewal

ID card renewal

Name and address changes

Name changes

Oregon DMV requires acceptable proof of a legal name change, such as a government-issued marriage certificate, domestic-partnership record, divorce or dissolution judgment, death certificate connecting a former spouse's name, adoption decree or court order. citeturn0search2

Address changes

Oregon allows an address update through DMV2U. A replacement credential can be issued when the resident wants the new residence address printed on the card. citeturn0search0

Oregon IDs for non-U.S. citizens

Oregon's REAL ID program permits several categories of non-U.S. citizens to obtain REAL ID when they can establish qualifying lawful status. Oregon DMV specifically lists permanent residents, conditional permanent residents, people with approved asylum and refugees among eligible categories, with credential terms varying by status. citeturn0search1

REAL ID documents

Examples of accepted lawful-status documents include a valid Permanent Resident Card, Employment Authorization Card and certain foreign passports accompanied by the required U.S. visa and I-94. citeturn0search2

SSN requirements

REAL ID applicants must provide a verifiable Social Security number or proof they are not eligible for one. Standard applicants must provide a verifiable SSN if one has been assigned. citeturn0search2

Limited-term credentials

When lawful status is temporary, the credential can have a limited term. Oregon DMV publishes separate limited-term fees for licenses, permits and ID cards. citeturn0search0

Oregon ID law FAQs

Is REAL ID mandatory in Oregon?

No. Oregon offers both standard and REAL ID-compliant driver's licenses, permits and identification cards.

How many proof-of-address documents do I need for Oregon REAL ID?

Two printed documents from two different sources showing your current Oregon residence address are required.

Can I use a P.O. Box as my Oregon residence address?

No. Oregon allows a mailing address such as a P.O. Box in addition to the residence address, but not in place of the residence address.

Does Oregon require ID to vote?

Oregon primarily votes by mail. Voter registration uses an Oregon DMV number or the last four digits of an SSN when available, with alternative identification documents for applicants who do not have those numbers.

Can non-U.S. citizens get an Oregon REAL ID?

Yes, qualifying noncitizens with lawful status can obtain REAL ID. The credential term can vary according to the person's lawful-status documentation.

How much does Oregon REAL ID cost?

The REAL ID option adds $30 to the regular driver's license, permit or ID transaction fee.

How much is an Oregon state ID?

The current eight-year original standard ID fee is $47. An eight-year original REAL ID is $77.

Can I replace my Oregon ID online?

Eligible customers may be able to replace a license, permit or ID through DMV2U. Some situations require an office visit and additional documentation.
