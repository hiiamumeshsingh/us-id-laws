Oklahoma ID Laws: What You Need to Know

Oklahoma issues both REAL ID-compliant and non-compliant driver licenses and identification cards. This guide covers required documents, Oklahoma residency, REAL ID, voter identification, renewals, replacements, fees and requirements that apply to non-U.S. citizens.

Last reviewed: September 26, 2026

Oklahoma driver license requirements

Service Oklahoma issues Class D driver licenses. New adult drivers must satisfy the state's identity-document process and complete the applicable written, vision and driving requirements before a license is issued. citeturn0search14turn0search18

First-time adult license

Applicants age 18 or older use Service Oklahoma's first-time driver license process. After completing the required testing, the current fee to print and issue a first-time Class D license is $42.50 for the four-year credential. citeturn0search14

Required documents

The documents required depend partly on whether the applicant chooses REAL ID. Service Oklahoma maintains a current required-document page and a separate REAL ID checklist rather than using one document combination for every applicant. citeturn0search6turn0search1

Out-of-state transfers

A new Oklahoma resident with an out-of-state license must transfer the credential through Service Oklahoma. An applicant who wants the transferred license to be REAL ID-compliant needs two proofs of Oklahoma residency in addition to the other required documents. citeturn0search26turn0search45

Oklahoma state identification cards

Oklahoma issues non-driver identification cards through Service Oklahoma. Residents can choose a four-year or eight-year card and can choose between a REAL ID-compliant and non-compliant credential when eligible. citeturn0search20turn0search42

Four-year state ID

Service Oklahoma currently lists $25 for an original four-year state ID, $25 for renewal and $25 for replacement. citeturn0search20turn0search12

Eight-year state ID

The current fee is $50 for an original or renewed eight-year state ID. Replacement is $25. citeturn0search20turn0search12

REAL ID state ID

A state ID can be issued as a REAL ID-compliant credential when the applicant supplies the additional documents required by the REAL ID checklist. citeturn0search1turn0search37

Documents needed for an Oklahoma ID

Service Oklahoma's required-document system is credential-specific. Applicants should use the current official checklist before visiting a licensing office because Standard/non-compliant and REAL ID transactions do not have identical documentation requirements. citeturn0search6turn0search1

Identity and lawful status

REAL ID applicants must provide an accepted identity and lawful-status document. The official checklist organizes acceptable documents by the fact they establish and provides additional instructions when the applicant's current name differs from the name on the foundational identity document. citeturn0search1

Social Security information

The REAL ID process requires the Social Security information specified by Service Oklahoma. Applicants should make sure their identity records and Social Security information are consistent before applying. citeturn0search1

Name changes

If an applicant's current legal name differs from the name shown on the primary identity document, supporting legal name-change documentation is required under the REAL ID checklist. citeturn0search1

Proof of Oklahoma residency

REAL ID applicants need two proofs of Oklahoma residency. The same two-document requirement applies when an out-of-state driver wants to transfer a license and make it REAL ID-compliant. citeturn0search1turn0search26

Preparing residency documents

The documents should meet Service Oklahoma's current checklist and show the required Oklahoma residential information. Because accepted documents and document-age rules can be credential-specific, applicants should confirm their exact documents against the official checklist before an appointment. citeturn0search1

Do not assume two residency proofs are required for every Oklahoma credential transaction. The two-document rule is specifically important for REAL ID. Non-compliant transactions follow the applicable Service Oklahoma document requirements. citeturn0search1turn0search6

Oklahoma REAL ID requirements

REAL ID is optional in Oklahoma. Residents can choose a REAL ID-compliant driver license or ID or keep a non-compliant state credential. citeturn0search42turn0search36

  • Social Security information/documentation required by the checklist

How to identify an Oklahoma REAL ID

REAL ID-compliant Oklahoma credentials display a star. Oklahoma's modernized credential program continues to offer both REAL ID-compliant and non-compliant versions. citeturn0search37turn0search25

Federal use

For covered federal purposes, including domestic air travel and entry to certain federal facilities, a REAL ID-compliant credential or another federally accepted document such as a U.S. passport is required. citeturn0search20turn0search44

2026 credential redesign

Service Oklahoma launched a modernized driver license and ID design in 2026. Existing Oklahoma credentials remain valid until expiration, so residents do not need to replace a valid card simply because the physical design changed. citeturn0search25

Oklahoma voter identification requirements

Oklahoma's proof-of-identity law requires every voter who votes in person at a precinct polling place or during early voting at a County Election Board to show proof of identity before receiving a ballot. The State Election Board describes three ways to meet the requirement. citeturn0search0

1. Show a qualifying photo ID

A voter can present a photo ID issued by the United States, the State of Oklahoma or a federally recognized tribal government if it meets the State Election Board's requirements. The name must substantially conform to the name in the precinct registry and the ID generally must not have expired before the date of the election, subject to the statutory exceptions described by the Election Board. citeturn0search0

2. Show the free voter identification card

Registered voters receive a voter identification card from the County Election Board. Oklahoma says this card can be used as proof of identity even though it does not contain a photograph. A replacement voter ID card can be requested at no charge. citeturn0search0turn0search10

3. Use the provisional-ballot process

A voter who cannot or does not provide proof of identity can cast a provisional ballot and sign a sworn affidavit. Election officials then verify the information according to the state's provisional-ballot procedure. citeturn0search0

Voter registration

Oklahoma requires eligible voters to register before voting. Registration applications can be submitted throughout the year but must generally be received at least 25 days before an election for the applicant to participate in that election. citeturn0search2

Renewing an Oklahoma driver license or ID

Existing Oklahoma driver licenses and state IDs can generally be renewed online or in person at a Licensed Operator or Service Oklahoma Licensing Office when the customer meets the eligibility requirements. citeturn0search4turn0search8

Driver license renewal fees

The current REAL ID fee page lists $38.50 for renewal of a four-year Class D credential and $77 for the eight-year option. citeturn0search1

State ID renewal fees

A four-year state ID renewal is $25. An eight-year state ID renewal is $50. citeturn0search12

One primary credential

Service Oklahoma notes that customers are permitted to hold only one primary credential. citeturn0search4

Replacing a lost, stolen or damaged Oklahoma ID

Oklahoma driver licenses and state IDs can be replaced online or in person when the customer is eligible. Service Oklahoma's replacement process can also be used to obtain a new physical credential after an address change. citeturn0search8turn0search4

Replacement fees

Service Oklahoma currently lists a $25 replacement fee for a Class D driver license that is still valid and $25 for replacement of either a four-year or eight-year state ID. citeturn0search1turn0search12

Name and address changes

Address changes

Service Oklahoma allows an address change online by requesting a replacement driver license or state ID. The new credential is then mailed to the customer. citeturn0search8

Name changes

Name changes cannot be completed through the same online replacement process. Service Oklahoma directs customers to a Licensed Operator or Licensing Office to request a duplicate credential with the updated name. Supporting legal documents may be required. citeturn0search8turn0search1

Oklahoma IDs for non-U.S. citizens

Oklahoma's credential process requires applicants to establish identity and the lawful-status information applicable to the credential. REAL ID applicants must satisfy the federal lawful-status requirements shown on Service Oklahoma's REAL ID checklist. citeturn0search1turn0search6

REAL ID

Non-U.S. citizens seeking REAL ID should use the official checklist for the immigration documents accepted for their particular status. The document used must satisfy the identity and lawful-status category rather than merely show a foreign identity. citeturn0search1

Credential validity

Temporary or limited lawful status can affect the duration and documentation of a credential. Because immigration categories differ, applicants should confirm the current Service Oklahoma requirements for their specific status before applying.

Oklahoma ID law FAQs

Is REAL ID mandatory in Oklahoma?

No. Oklahoma residents can choose a REAL ID-compliant or non-compliant driver license or state ID.

How many proofs of residency do I need for Oklahoma REAL ID?

Two proofs of Oklahoma residency are required for REAL ID.

How much is a first-time Oklahoma driver license?

The current issuance fee for a first-time four-year Class D driver license is $42.50.

How much is an Oklahoma state ID?

A four-year original or renewed state ID is $25. An eight-year original or renewed state ID is $50. Replacement is $25.

Does Oklahoma require photo ID to vote?

Oklahoma requires proof of identity for in-person voting, but a photo ID is not the only option. A registered voter can also use the voter identification card issued through the election system.

What if I have no voter ID at the polling place?

You can vote a provisional ballot after signing the required sworn affidavit. Election officials then verify the information under the state's provisional-ballot process.

Can I renew an Oklahoma driver license online?

Yes, eligible customers can renew or replace an existing Oklahoma driver license online or complete the transaction in person.

Can I change my name online on my Oklahoma license?

No. Service Oklahoma says name changes must be handled in person at a Licensed Operator or Licensing Office.
